Limpide

Effacement EXIF et conversion HEIC → JPEG, entièrement dans votre navigateur. Vos fichiers ne quittent jamais votre appareil — vérifiable ligne par ligne dans le dépôt GitHub.

Rien gardé, à aucun point

  • Pas d'upload — aucune requête réseau vers un serveur de traitement
  • Pas de base de données — pas de compte, pas de cookie de suivi
  • Pas de fichier temporaire côté serveur — il n'y a pas de serveur
  • Code auditable — web/app.js fait tout le travail localement

Effacer les EXIF

JPEG, PNG, WebP — les métadonnées (GPS, appareil, date…) sont retirées par réencodage local.

HEIC → JPEG

Convertissez les photos iPhone (.heic, .heif) en JPEG standard, sans les envoyer en ligne.

CLI Python disponible dans le même dépôt : limpide strip-exif · limpide convert-heic
